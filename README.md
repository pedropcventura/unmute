# Unmute

Apresentação em formato de site sobre o Unmute, proposta conceitual de óculos de legendas em tempo real para pessoas surdas.

Abra `index.html` no navegador ou acesse a versão publicada no GitHub Pages.

**Atalhos:** ← → navegar · I índice · P modo apresentador (roteiro e cronômetro em outra janela) · F fontes da tela · Esc fechar.
